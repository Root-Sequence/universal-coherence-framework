# UCF models

These are living model proposals, not proof of a universal mechanism.

- [Model v1](ucf-model-v1.md): earlier specification, retained unchanged. It defines four analytical layers; the old index incorrectly described it as specifying four states. Its categorical cross-domain-comparability wording remains historical, not validated.
- [Model v1.1 draft](ucf-model-v1.1-draft.md): proposed reconciliation of those layers with state labels, definitions, limits, and evidence requirements. AI-assisted; author review pending.
- [Cross-intelligence notes](cross-intelligence-notes.md): existing cross-system applications and analogies, not independently audited by this revision.
- [Booking-service example](examples/booking-service/README.md): constructed arithmetic example, implementation tests, and an assessment of what the vocabulary does and does not add.

Mathematical formalization, domain metrics, diagrams, ontologies, simulations, and diagnostics remain possible research directions. No universal coherence score or completed validation follows from the directory's existence.
